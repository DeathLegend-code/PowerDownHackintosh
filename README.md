# Power Down Hackintosh!

Лёгкая нативная утилита для macOS / Hackintosh (написана на Objective-C без сторонних зависимостей), которая позволяет выключать компьютер **мгновенным нажатием на физическую кнопку питания на корпусе** — без удержания кнопки и без всплывающего системного окна «Перезагрузить / Режим сна / Выключить».

## Как это работает
1. Отключает системную задержку/сон по короткому нажатию кнопки питания (`PowerButtonSleepsSystem = no`).
2. Вешает лёгкий фоновый демон (`LaunchAgent`), который перехватывает системное событие `NX_POWER_KEY` через `CGEventTap` и сразу запускает штатное завершение работы macOS.

## Требования
* macOS (проверено на Sonoma версии 14.8.9)
* Установленные Command Line Tools (`xcode-select --install`) для сборки

## Установка

Склонируй репозиторий и запусти скрипт установки:

```bash
git clone https://github.com/DeathLegend-code/PowerDownHackintosh
cd PowerDownHackintosh
chmod +x install.sh
./install.sh
```

### Обязательный шаг после установки:
1. Открой **Системные настройки -> Конфиденциальность и безопасность -> Универсальный доступ**.
2. Нажми **+**, в окне выбора нажми `Cmd + Shift + G`, вставь `/usr/local/bin/PowerOff` и добавь файл.
3. Включи тумблер напротив **PowerOff**.
4. Один раз перезагрузи компьютер через меню ``.

## Удаление

```bash
./install.sh uninstall
```
